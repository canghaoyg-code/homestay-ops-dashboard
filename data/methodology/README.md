# Investment research data

This directory is the source of truth for investment content rendered by the site.

- `countries/` holds country-level facts and macro indicators.
- `cities/` holds one city profile per file.
- `methodology/` holds source records and metric definitions.

Every quantitative claim must include its source URL, reference period, retrieval date, and whether it is an observed figure, an estimate, or an internal score. Do not present unsupported assumptions as market data.
